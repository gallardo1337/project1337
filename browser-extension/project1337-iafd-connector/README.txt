PROJECT1337 IAFD CONNECTOR – EDGE / CHROME

Die Erweiterung verbindet einen normalen IAFD-Browser-Tab mit dem Import-Assistenten.
Cloudflare wird dadurch von deinem echten Browser geprüft und nicht von Playwright.

INSTALLATION IN MICROSOFT EDGE

1. ZIP-Datei vollständig entpacken.
2. edge://extensions öffnen.
3. Links unten den Entwicklermodus einschalten.
4. "Entpackte Erweiterung laden" anklicken.
5. Den entpackten Ordner "project1337-iafd-connector" auswählen.
6. Das bereits geöffnete Project1337-Preview einmal neu laden.

INSTALLATION IN GOOGLE CHROME

1. ZIP-Datei vollständig entpacken.
2. chrome://extensions öffnen.
3. Rechts oben den Entwicklermodus einschalten.
4. "Entpackte Erweiterung laden" anklicken.
5. Den entpackten Ordner "project1337-iafd-connector" auswählen.
6. Das bereits geöffnete Project1337-Preview einmal neu laden.

DATENSCHUTZ

Die Erweiterung läuft nur auf iafd.com und den fest eingetragenen Project1337-Seiten.
Sie übergibt ausschließlich das bereinigte HTML der öffentlich geöffneten IAFD-Seite
an den Project1337-Tab, der diese Seite selbst geöffnet hat. Cookies, Passwörter,
Verlauf, lokale Dateien und andere Webseiten werden nicht gelesen oder übertragen.
